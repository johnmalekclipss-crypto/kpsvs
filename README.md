# KPSVS — Kedar Prasad Sushil Verma Sarraf

Official showcase and digital showroom website for **Kedar Prasad Sushil Verma Sarraf (KP SVS)**, founded and owned by **Sushil Verma**, situated in **Naurangiya, Padrauna, Uttar Pradesh**.

---

## 💎 Features

- **Royal Heritage Visual Identity**: Warm gold and onyx luxury color scheme crafted for fine jewellery.
- **Jewellery Collections**: Gold jewellery, Silver ornaments, Grand bridal sets, Antique temple art, Diamond rings, Bangles & Payals.
- **Interactive Lightbox Gallery**: Curated high-resolution showcase of pieces with direct enquiry triggers.
- **Direct WhatsApp & Phone Integration**: One-tap enquiries connected directly to showroom proprietor Sushil Verma.
- **Store Location & Hours**: Embedded Google Maps directions, address, and live hours indicators.
- **Responsive & High-Performance**: Optimized for all devices, fast Core Web Vitals, and accessibility.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Deployment**: GitHub Pages (via GitHub Actions)

---

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```

### 4. Preview production build
```bash
npm run preview
```
